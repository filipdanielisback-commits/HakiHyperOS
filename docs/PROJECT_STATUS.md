**Overall stage: Documentation and feasibility research.**

No HakiHyperOS port has been built or booted. No device compatibility has been demonstrated.

- [ ] Define a reproducible build environment and source manifest.

- [ ] Validate functionality through documented, controlled testing before making any release claims.

## Status vocabulary

- **Not started** — no investigation or implementation recorded.
- **Researching** — gathering and checking sources.
- **In progress** — implementation exists but is incomplete.
- **Tested** — a specific test was run; include device/build details and results.
- **Verified** — reproducible evidence supports the claim.

A successful build is not the same as a successful boot, and a successful boot is not proof that all hardware works.
